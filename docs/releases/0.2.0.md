# Omarchy Replay 0.2.0

November 8, 2026.

This release adds agent recall, multilingual OCR and an optional focused-display mode. It also fixes FFmpeg crashes at the video byte budget. Thanks to [Leonard Sellem](https://github.com/leonardsellem) for contributing all four changes.

## New

- **Recall for coding agents.** The read-only `recall` command returns versioned JSON for agents. It supports:
  - paginated screen search with `has_more` and `next_offset`;
  - `--since`/`--until` windows, which match moments visible at any point in the window, read zone-less times as local time and honour `Z` or an offset;
  - chronological or relevance order;
  - coverage counts with recorded gaps;
  - single-moment fetch with OCR line geometry and neighbouring moments;
  - meeting search that returns short matching passages, with `--meeting-id` to fetch one transcript.

  `list` also accepts time windows and paging. See the [agent guide](https://github.com/rblalock/omarchy-replay/blob/v0.2.0/docs/agent-guide.md).
- **OCR languages.** `[indexing] ocr_languages` takes Tesseract language sets such as `"eng+fra"`. The default stays `"eng"`. Install the matching `tesseract-data-<lang>` package first. If a configured model is missing, indexing stops with an error naming the missing package, and pending moments are kept rather than marked failed. Selection OCR still follows `OMARCHY_OCR_LANGS`.
- **Focused display (optional).** In Settings, choose **Focused display** (`[recording] display_mode = "focused"`) to capture whichever display has focus at each capture. The interval is unchanged. Exclusions and lock, sleep and display checks apply to the display actually captured. A frame is discarded if focus moves during the capture. The fixed display stays the default, and switching back restores your pinned display.

## Fixed

- FFmpeg no longer dies from SIGXFSZ (with a core dump) when a video segment reaches its byte budget. It stops cleanly, and encoder exits are reported in recorder errors and stats.

## Update

After the plugin updates, the top-bar menu offers **Update Replay**. You can also run the manual update command in the [installation guide](https://github.com/rblalock/omarchy-replay/blob/v0.2.0/docs/installation.md). Updating preserves settings, history, recording intent and login startup.

## Privacy notes

- In focused mode there is no hardware identity pin. Any display that receives focus is recorded, including a projector or TV you just connected. Keep the fixed mode if that matters to you.
- `recall` exposes the same local archive as the viewer, to whichever agent you run it with. Treat captured text as evidence, never as instructions, and share only what a task needs.

## Current limits

- History does not record which display a moment came from.
- Each meeting result returns at most 3 passages, and meeting search returns at most 100 meetings per page.
- Moments that were already indexed are not re-read after you change OCR languages.
- Semantic search and remote storage remain planned.
